# Пояснение к словарю замен `terms_map.json`

## Какую вселенную взяли
**Marvel** (кинематографическая вселенная и комиксы): команда героев-защитников, боги из другого мира, космические империи, камни силы, тайные агентства и злодей, который хочет «уравновесить» мироздание.

## Во что превратили
Новая вселенная называется **«Эйтрин»**. Сюжетная логика сохранена, а все имена, названия рас, оружия, планет и событий заменены.

| Категория | Пример замены |
|---|---|
| Герои | Железный человек → **Ферро-Страж** (Эдгар Харкхейл); Капитан Америка → **Страж Бастион** (Уэсли Брэнтон); Тор → **Вельтар Громовержец** |
| Злодеи | Танос → **Мальгор Опустошитель**; Альтрон → **Вектор-9**; Локи → **Ликар Плут** |
| Планеты и места | Земля → **Тэллур**; Асгард → **Скальхейм**; Ваканда → **Зандара**; Нью-Йорк → **Нордхейвен** |
| Расы | Крии → **Каррины**; Скруллы → **Ваалы**; Читаури → **Ржавая Орда** |
| Организации | Мстители → **Хранители Зари**; Щ.И.Т. → **Заслон**; Гидра → **Орден Щупальца** |
| Оружие и артефакты | Камни Бесконечности → **Осколки Вечности**; Мьёльнир → **Грозовей**; Вибраниум → **лумирий** |
| События | Битва за Нью-Йорк → **Битва за Нордхейвен**; Щелчок → **Великое Угасание**; Мстители: Финал → **Последняя Партия** |

## Как заменяли
1. **Сохранили роль и смысл.** У каждого персонажа осталась функция из оригинала (гений-изобретатель, суперсолдат, бог грома и т. д.), поэтому логика мира читается так же.
2. **Имена подбирали в одном стиле.** Фамилии героев Тэллура звучат как англо-германские (Харкхейл, Брэнтон, Пэйсли), названия скальхеймцев скандинавские (Вельтар, Хродгар), названия космических рас короткие и гортанные (Каррины, Ваалы).
3. **Говорящие прозвища.** Они описывают суть: Верхолаз лазает по стенам, Ночная Гадюка бьёт жалом, Кроха-Исполин меняет размер.
4. **Заменили и «механику» мира.** Паук-мутант стал геккон-мутантом, укус паука стал укусом геккона, но способности (лазание, чутьё опасности) остались.
5. **Календарь сдвинут.** Реальные годы пересчитаны в **г.З.** («год Зари») по формуле `год − 1942`.
6. **Формат.** Все документы — простой текст без JSON и HTML.

## Что в папке
- `universe_docs/` — **47 документов** (только чистый текст `.txt`: герои, злодеи, локации, организации и расы, артефакты, события, хронология, обзор).
- `terms_map.json` — словарь «оригинал → замена» по категориям.
- `build_universe.py` — скрипт, который создаёт всё выше и сам проверяет, что в документах не осталось ни одного оригинального названия.

## Проверка
После генерации скрипт ищет в документах каждый оригинальный термин из словаря (кроме коротких слов, совпадающих с обычными словами русского языка, например «Земля» или «Один»). Результат: «Утечки оригинальных имён: нет».
